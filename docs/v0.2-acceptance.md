# v0.2.x acceptance record

Tracks the ROADMAP v0.2.x gate and the SECURITY.md §14 stage gate against repeatable evidence.
Update this file whenever evidence changes; a gate item is **Met** only with a reproducible check.

Evidence sources:
- **unit**: `pytest -q` (SQLite, in-memory MCP; CI job `test`)
- **e2e**: `python3 e2e/smoke.py --restart` against `docker-compose.yml + compose.e2e.yaml` (PostgreSQL/pgvector, harness image, OpenAI-compatible stub, streamable-HTTP MCP server; CI job `e2e`)
- **real**: `python3 e2e/real_model_check.py [--provider …]` against real models (run by an operator)

Last full run: 2026-09-23, PR gilbertomende/harness#1 — unit 78/78, e2e 30/30 (re-run on the same database 29/29), CI green.

## Known gaps (not required for v0.2 stage; tracked for v0.3/v0.4)

- OIDC/RBAC and separation of duties between requester and approver (single bootstrap admin today).
- Alembic migrations (additive startup DDL is a bridge).
- Isolated execution for EXEC tools (application sandbox only).
- Rate limiting, OpenTelemetry, backups/restore, pinned dependencies and images (`ollama/ollama:latest`).
- RAG ACLs/collections/citations; HNSW index; embedding-model migration.
- MCP authentication and egress control; `MCP_ALLOWED_HOSTS` must be set before production.
